# Bhupesh Nemade — Professional Portfolio

A recruiter-focused portfolio built with Next.js, TypeScript, and Tailwind CSS.

## Design direction

- Professional light base with richer navy, indigo, coral, teal, and warm neutral sections.
- No 3D scenes, cinematic effects, custom cursor, smooth-scroll library, or heavy motion system.
- Clear hierarchy designed for quick HR/recruiter scanning.
- Interactive skill filters, project case-study modal, scroll-aware navigation, responsive menu, and contact form.
- Responsive layout for desktop, tablet, and mobile.

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- React Hook Form + Zod
- EmailJS
- Lucide React

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Validation

`npm run typecheck` passes.

A production build requires the Next.js SWC binary. The provided sandbox did not have external npm registry access to download that binary, so `npm run build` could not be completed there.
